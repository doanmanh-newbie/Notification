# Nhắc Việc — Kế hoạch triển khai (thành sản phẩm + thông báo đẩy Android)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Biến app nhắc việc hiện có thành PWA có đăng nhập, đồng bộ Supabase, việc lặp lại, snooze, và thông báo đẩy tới Android kể cả khi app đã đóng.

**Architecture:** Client React giữ nguyên cấu trúc `useStore` (state + cache `localStorage`), thêm lớp đồng bộ last-write-wins với bảng Supabase (mỗi task là một hàng `data jsonb` + cột phục vụ máy chủ). `pg_cron` gọi Edge Function `send-reminders` mỗi phút để gửi Web Push (VAPID); service worker hiện thông báo với nút *Xong* / *Hoãn 10 phút* gọi Edge Function `notification-action`. Logic thuần (lặp lại, giờ/múi giờ, kết quả gửi) nằm ở `supabase/functions/_shared/` để client và Deno dùng chung một bản.

**Tech Stack:** React 19, Vite 8, Tailwind 4, TypeScript 5.7, pnpm, Vitest, `@supabase/supabase-js@2`, Supabase (Postgres + RLS, Auth magic link, Edge Functions Deno, `pg_cron`, `pg_net`, Vault), `npm:web-push@3.6` trong Deno.

**Spec:** `docs/superpowers/specs/2026-11-19-nhac-viec-design.md`

**Supabase project ref:** `lsznbtcmrbeougdjgnye` (URL `https://lsznbtcmrbeougdjgnye.supabase.co`).
⚠️ Kết nối Supabase MCP hiện **không có quyền** với dự án này (chỉ thấy `FORE`, `learntoday`). Trước Task 4 phải giải quyết: chủ dự án kết nối lại MCP bằng tài khoản sở hữu dự án, hoặc mời tài khoản đó vào tổ chức.

- Toàn bộ chữ trên giao diện và trong thông báo bằng **tiếng Việt**; giữ phong cách giao diện hiện có (nền `#f7f6f3`, stone, Inter / Source Serif 4).
- Nền tảng đích đợt này: **Android Chrome**. Không làm riêng cho iOS.
- Deploy tĩnh (`.figma/make/deploy.json` `adapter: static`); mọi đường dẫn tài nguyên phải tôn trọng `import.meta.env.BASE_URL` (có thể là thư mục con qua `FIGMA_PUBLIC_URL`).
- Khoá riêng VAPID và service role key **không bao giờ** nằm trong code client hay git; chỉ ở Supabase Vault / biến môi trường Edge Function.
- Chỉ public: `SUPABASE_URL`, anon key, VAPID public key — đặt trong `src/lib/config.ts`.
- Bật RLS trên mọi bảng `public`; mỗi người chỉ đọc/ghi hàng có `user_id = auth.uid()`.
- Không làm mất dữ liệu `localStorage` hiện có (key `nhac-nho-v1`).
- Độ trễ nhắc ≤ ~1 phút (cron mỗi phút).
- Xung đột đồng bộ: **bản có `updated_at` mới nhất thắng**.
- Không thêm dependency ngoài: `@supabase/supabase-js`, `vitest` (client) và `npm:web-push`, `jsr:@supabase/supabase-js` (Edge Function).

Mọi file `_shared` không import gì ngoài nhau, import bằng đuôi `.ts`, không dùng `Date` theo múi giờ máy chạy (chỉ `Date.UTC` / `getUTC*`).

**Interfaces:**
- Produces (`time.ts`):
  - `toUtcIso(local: string, offsetMin: number): string` — `local` dạng `yyyy-mm-ddThh:mm`; `offsetMin` theo quy ước `Date#getTimezoneOffset` (VN = `-420`).
  - `toLocal(utcMs: number, offsetMin: number): string` → `yyyy-mm-ddThh:mm`.
  - `addDaysToDate(date: string, n: number): string` (`yyyy-mm-dd`), `addMonthsClamped(date: string, n: number): string`.
- Produces (`recur.ts`): `type Repeat`; `nextOccurrence(date: string, repeat: Repeat): string` (date hoặc datetime cục bộ, giữ nguyên phần giờ); `rollForward<T extends RollTask>(task: T): T` với `RollTask = { due: string|null; remindAt: string|null; repeat: Repeat; done: boolean; reminded: boolean; subtasks: {done:boolean}[] }` — đẩy `due`/`remindAt` sang lần kế (lấy mốc `due ?? remindAt` ; nếu chỉ có một trường thì chỉ đẩy trường đó), đặt `done:false`, `reminded:false`, mọi subtask `done:false`. `repeat:'none'` → trả `{...task, done:true}`.
- Produces (`delivery.ts`): `afterSend(results: { endpoint: string; status: number }[]): { reminded: boolean; deadEndpoints: string[] }` — `reminded` = có ít nhất một status 2xx; `deadEndpoints` = status 404 hoặc 410.

export interface TaskRow { id: string; user_id: string; data: Task; remind_at: string | null; tz_offset: number; action_token: string | null; deleted: boolean; updated_at: string }

mergeProjects(local: Project[], remote: ProjectRow[]): { projects: Project[]; toPush: Project[] }

  - Bảng `public.push_subscriptions(endpoint text primary key, user_id uuid … , p256dh text not null, auth text not null, created_at timestamptz default now())`.

  - Edge Function `send-reminders` (`verify_jwt: false`, yêu cầu header `x-cron-secret` khớp secret Vault `cron_secret`): lấy tối đa 200 hàng `remind_at <= now() and not deleted` của user có ít nhất một subscription; với mỗi hàng: tạo `action_token` mới, gửi tới mọi subscription của user payload JSON `{ taskId, title, body, token, userId }` (`body` = nhãn hạn hoặc "Đến giờ rồi", TTL 3600, urgency `high`); gọi `afterSend`; xoá `deadEndpoints`; nếu `reminded` thì `update tasks set data = data || '{"reminded":true}', remind_at = null, action_token = <token>, updated_at = now()`.
  - Edge Function `notification-action` (`verify_jwt: false`, CORS cho mọi origin, POST `{ userId, taskId, token, action: 'done' | 'snooze' }`): kiểm tra `action_token` khớp (sai → 403); `done` → `data = rollForward(data)` và nếu còn `remindAt` thì `remind_at = toUtcIso(remindAt, tz_offset)`; `snooze` → `remindAt = toLocal(now + 10 phút, tz_offset)`, `reminded = false`, `remind_at = now + 10 phút`. Cả hai: `action_token = null`, `updated_at = now()`.

  - Cron `send-reminders-every-minute` (`* * * * *`) dùng `net.http_post` tới `https://lsznbtcmrbeougdjgnye.supabase.co/functions/v1/send-reminders` với header `x-cron-secret` đọc từ Vault.
