## Task 1: `src/lib/calendar.ts` (test trước: `src/lib/calendar.test.ts`)
- `monthGrid(year: number, month0: number): string[]` — 42 ngày `yyyy-mm-dd`, bắt đầu thứ Hai của tuần chứa ngày 1.
- `taskDay(t: Task): string | null` — `due ?? remindAt.slice(0,10) ?? null`.
- `groupByDay(tasks: Task[], projectId?: string | null): Map<string, Task[]>` — sắp: chưa xong trước, theo thứ tự ưu tiên, rồi giờ nhắc.
- `CAPACITY_MIN = 360`; `dayLoad(tasks: Task[]): { minutes: number; pct: number; level: 'free'|'ok'|'busy'|'over' }` — chỉ việc chưa xong; busy > 60%, over > 100%.
- `moveToDay(t: Task, day: string): Partial<Task>` — `{ due: day }` + nếu có `remindAt` thì `day + 'T' + giờ cũ`, `reminded: false`.
- `freeDays(from: string, byDay: Map<string, Task[]>, count = 3, horizon = 21): string[]` — các ngày sau `from` có tải ≤ 60%, không tính quá khứ.
- `lightestToMove(tasks: Task[]): Task | null` — việc chưa xong, ưu tiên thấp nhất, rồi nhẹ nhất.
Test các giá trị: lưới 11/2026 bắt đầu 2026-10-26, chứa 2026-11-01, 42 phần tử; dời giữ "08:00"; tải 7×45' = 315' → busy; 9×45' → over; freeDays bỏ ngày quá tải.
